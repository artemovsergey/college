# Шаблоны документов

| Файл | Что это | Когда использовать |
|---|---|---|
| `rp-pm.docx` | Рабочая программа профессионального модуля, ФГОС 3 | РП на весь ПМ |
| `rp-pm.doc` | Исходный `.doc` колледжа | Сверка и повторная конвертация |
| `rp-ud.docx` | Рабочая программа учебной дисциплины, ФГОС 3 | РП на дисциплину |
| `rp-ud.doc` | Исходный `.doc` колледжа | Сверка и повторная конвертация |
| `ktp.docx` | Календарно-тематический план, ФГОС 3 | КТП на семестр |
| `titlepage.md` | Титульный лист методички | Сборка методички |

`.docx` — рабочие копии для `python-docx`/`docxtpl`; `.doc` — оригиналы.
Если оригинал обновился, переконвертируйте его:

```bash
soffice -env:UserInstallation=file:///tmp/lo_profile \
  --headless --convert-to docx --outdir templates templates/rp-pm.doc
```

Шаблоны — официальные бланки колледжа. Не меняйте в них структуру разделов и
таблиц; заполняйте существующие абзацы и ячейки. Если добавляете плейсхолдеры
`{{ ... }}`, проверьте, что `docxtpl` их видит, и не оставляйте незаполненных.
