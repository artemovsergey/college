# AGENTS.md — репозиторий предмета

Правила для агентов, которые работают с одним предметом или МДК.
Общие правила машины, git и секретов — в глобальном
`~/.config/opencode/AGENTS.md`. Архитектура пайплайна — в
`docs/architecture.md`.

## 1. Что является источником правды

- `course.yaml` — метаданные, часы, стек.
- `syllabus/rp.yml` — рабочая программа в структурированном виде.
- `syllabus/ktp.yml` — календарно-тематический план.
- `course/**/*.md` — содержание занятий; у каждого файла есть frontmatter.
- `syllabus/normative.yml` — реестр нормативных документов.
- `syllabus/sources.yml` — учебные источники для занятий.
- `plan.yml` — производный манифест для сборки; руками не правится.
- `dist/` — собранные DOCX, PDF, PPTX, сайт, JSON для LMS; в git не коммитится.

Если факт встречается в двух местах, прав тот файл, который выше в этом списке.
`plan.yml` пересобирается из `ktp.yml` и frontmatter, а не наоборот.

## 2. Структура

```text
course-<slug>/
├─ AGENTS.md
├─ README.md
├─ course.yaml
├─ plan.yml                 # генерируется
├─ syllabus/
│  ├─ rp.md / rp.yml / rp.docx
│  ├─ ktp.md / ktp.yml / ktp.docx
│  ├─ normative.yml
│  ├─ sources.yml
│  ├─ outcomes.yml
│  ├─ competency-matrix.md
│  └─ normative/            # ФГОС, профстандарт, учебный план
├─ course/
│  └─ chapter-01/
│     ├─ lecture-01.md
│     ├─ practice-01.md
│     ├─ selfwork-01.md
│     ├─ presentation-01.md
│     ├─ test-01.yaml
│     └─ assets/
├─ projects/                # сквозные проекты и эталоны
├─ templates/               # Word-шаблоны РП, КТП, титула
├─ .agents/skills/          # скиллы, переносимые между оболочками
├─ .opencode/agents/        # агенты OpenCode
└─ .github/workflows/       # CI
```

Имена глав и занятий — латиницей: `chapter-01`, `lecture-01.md`. Старые
репозитории с `Раздел N` и `Лекция N` не переименовываются без отдельной задачи.

## 3. Роли и скиллы

| Роль | Агент | Скилл | Результат |
|------|-------|-------|-----------|
| Архитектор курса | `course-architect-agent` | `init-course-repository` | репозиторий, `course.yaml`, `AGENTS.md`, заготовка CI |
| Архитектор курса | `course-architect-agent` | `create-rp` | `syllabus/rp.*`, `normative.yml`, `outcomes.yml` |
| Архитектор курса | `course-architect-agent` | `create-ktp` | `syllabus/ktp.*`, заготовки занятий |
| Планировщик | `course-planner-agent` | `build-course-plan` | `plan.yml` |
| Лектор | `lecturer-agent` | `write-lecture` | `lecture-NN.md` |
| Практик | `practitioner-agent` | `create-practice` | `practice-NN.md`, `selfwork-NN.md` |
| Презентатор | `presenter-agent` | `build-slides` | `presentation-NN.md` |
| Оформитель | `formatter-agent` | `assemble-methodichka` | `dist/docs/*.docx`, `*.pdf` |
| Методист | `methodist-agent` | — | отчёт по рубрике, без правки файлов |

Начальный контур реализован: `course-architect-agent`, `methodist-agent`,
`init-course-repository`, `create-rp`, `create-ktp`. Остальные роли появятся
вместе со скиллами материалов и проверяются по тому же контракту.

## 4. Ворота

| Этап | Кто проверяет | Критерий |
|------|---------------|----------|
| Репозиторий | `course-architect-agent` | структура на месте, `course.yaml` заполнен, секретов нет |
| РП | `methodist-agent`, рубрика «РП/КТП» | часы сходятся, компетенции покрыты, разделы шаблона на месте, нет `{{ }}` и `TODO` |
| КТП | `methodist-agent`, рубрика «РП/КТП» | часы семестра сходятся, практика идёт после лекции-опоры, нет раздела без практики |
| Материал | `methodist-agent`, рубрика «материал» | структура, факты, код, визуалы и вопросы соответствуют скиллу |
| Методичка | `methodist-agent`, рубрика «оформление» | титул, содержание, приложения и источники на месте; сборка без ошибок |

После методиста результат смотрит преподаватель. Без его решения нельзя менять
часы, номера и состав занятий.

## 5. Правила

- Не выдумывать номера ФГОС, приказы, профстандарты, API и версии библиотек.
  Нормативное требование — только из документа в `syllabus/normative/`.
- Если документа нет, агент останавливается и пишет, чего не хватает. Он не
  заполняет пробел правдоподобным текстом.
- Не править `syllabus/normative/**`, `rp.docx`, `ktp.docx` и `plan.yml` руками.
  Правка — в источнике, затем пересборка.
- Не менять часы и состав занятий без явного решения преподавателя.
- Не коммитить секреты, токены, пароли, персональные данные и внутренние адреса.
- Язык материалов — русский; термин определяется при первом употреблении.
- Блок кода — с языком и строками не длиннее 80 символов. Вывод консоли —
  отдельный блок `text`.
- Скриншот — только фактический прогон; чужие данные и токены вырезаны.
- `TODO` и заглушки запрещены. Если скриншота нет, ставится явная пометка
  `> **Скриншот отсутствует:**` с причиной.

## 6. Готовность

РП и КТП готовы, когда:

- часы сходятся на всех уровнях: модуль → МДК → семестр → занятия;
- компетенции из ФГОС/РП покрыты и состыкованы с занятиями;
- DOCX собран из шаблона колледжа, таблицы не разъехались;
- в тексте нет `{{ }}`, `TODO` и вымышленных источников;
- методист не имеет blocker и major;
- преподаватель подтвердил результат.

Материалы занятий готовы, когда выполнены чек-лист своего скилла, тесты
эталонных решений зелёные, а методист не имеет blocker и major.
