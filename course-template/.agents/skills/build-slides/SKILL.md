# Презентация к лекции

## Когда применять

- после лекции, когда в `plan.yml` у занятия есть `slides`;
- переработка существующей колоды под стандарт;
- перед сборкой PPTX/PDF.

## Вход

- `plan.yml` — занятие по `id`: `file`, `slides`, часы, outcomes;
- `course.yaml` — курс, группа, стек;
- файл лекции целиком;
- существующая колода, если её перерабатывают.

Колода не начинается, пока лекция не готова: слайды не добавляют факты,
которых нет в лекции.

## Границы

- одна лекция на 2 ч — 15–20 слайдов, допустимо 12–24;
- колода — опора для речи, не конспект и не копия лекции;
- новые факты, примеры и схемы не выдумываются;
- практики, СР и экзамены — не эта зона.

## Формат

- один файл: `slides/chapter-NN/presentation-NN.md`;
- слайды разделяются строкой `---`;
- первый заголовок `#`, остальные `##`;
- заметки — `<!-- notes: ... -->` в конце слайда;
- обязательны титул, план, содержательные разделы, резюме, вопросы;
- на каждый `##` лекции — минимум один слайд;
- один слайд = один тезис; заголовок — утверждение, не «DbContext»;
- не больше 6 пунктов и 70 слов на слайд;
- код — не больше 12 строк и 80 символов в строке;
- схема — одна на слайд, из лекции, с подписью; файл должен существовать;
- русский язык, кавычки-ёлочки, термины как в лекции.

## Заметки

В каждом слайде:

- что сказать — 1–2 предложения;
- вопрос или пример для аудитории;
- время на слайд;
- что показать на доске или в IDE.

Без заметок слайд не сдан.

## Проверка

- 12–24 слайда, все разделы лекции покрыты;
- нет абзацев из лекции и новых фактов;
- лимиты слов, пунктов и кода соблюдены;
- заметки есть на каждом слайде;
- схемы и файлы существуют;
- колода собирается выбранным инструментом; если рендер не настроен,
  сдаётся Markdown с заметками и честной пометкой;
- отчёт: `docs/slides-01-review.md` — объём, покрытие, проверки, замечания.

## Запреты

- 50–70 слайдов и стена текста;
- код на 30 строк и без языка;
- слайд без заметок;
- схема ради схемы и выдуманный интерфейс;
- «Спасибо за внимание» как содержательный слайд;
- новые факты, которых нет в лекции.
