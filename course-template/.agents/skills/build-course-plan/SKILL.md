# Построить план курса

## Когда применять

- КТП уже собран и проверен, заготовки занятий лежат в `course/`.
- Нужно получить `plan.yml` для материалов, презентаций и сборки.
- КТП изменился и `plan.yml` нужно пересобрать.

`plan.yml` — производный манифест. Руками не правится: источник — `course.yaml`,
`syllabus/ktp.yml`, `syllabus/outcomes.yml` и frontmatter заготовок.

## Вход

- `course.yaml` — код, название, специальность, группа, курс, преподаватель, часы.
- `syllabus/ktp.yml` — разделы, занятия, ID, виды, часы, результаты.
- `syllabus/outcomes.yml` — коды и формулировки ПК/ОК.
- `course/**/*.md` — заготовки с frontmatter: `id`, `kind`, `number`, `title`,
  `hours`, `prerequisites`, `outcomes`, `sources`, `file`, `slides`, `planned`.

Если нет `ktp.yml` или заготовок — стоп: сначала `create-ktp`.

## Порядок

1. Проверь вход: `ktp.yml` парсится, у каждого занятия есть `id`, `kind`, `hours`,
   `outcomes`, `file`; файлы заготовок существуют.
2. Запусти из корня репозитория:

   ```bash
   python3 .agents/skills/build-course-plan/scripts/build_plan.py --check
   python3 .agents/skills/build-course-plan/scripts/build_plan.py
   ```

   Первый запуск только проверяет, второй пишет `plan.yml`.
3. Проверь итог: число разделов и занятий, сумма часов, уникальность ID,
   пререквизиты идут раньше, все `file` существуют, коды результатов известны.
4. Напиши `docs/plan-review.md`: источник, сколько разделов/занятий/часов,
   сколько заготовок (`planned: true`), расхождения с КТП, что осталось.
5. Передай отчёт преподавателю. Материалы не пиши.

## Проверки

- Сумма часов занятий в разделе равна часам раздела в КТП.
- Сумма разделов равна `hours.total` из `course.yaml`.
- ID занятий уникальны; пререквизит не идёт позже занятия.
- У каждого занятия есть существующий `file`.
- Все коды `outcomes` есть в `outcomes.yml`.
- В `plan.yml` нет `TODO`, `{{ }}` и пустых обязательных полей.

## Запреты

- Не редактировать `plan.yml` руками — только пересборка.
- Не менять `ktp.yml`, `course.yaml` и заготовки под план.
- Не добавлять занятия, которых нет в КТП.
- Не выдумывать результаты, пререквизиты и источники.
- Не писать лекции, практики и презентации на этом этапе.

## Результат

- `plan.yml` — машинный манифест.
- `docs/plan-review.md` — отчёт о сборке и проверках.
- Список открытых вопросов, если КТП и заготовки расходятся.
