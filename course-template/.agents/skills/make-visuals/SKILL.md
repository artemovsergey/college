# Визуалы

## Когда применять

- схема, скриншот, график или иллюстрация нужна для одного тезиса;
- визуал проверяется глазами после рендера.

## Типы

- схема: связи, процесс, архитектура, состояние; исходник `.excalidraw`;
- скриншот: реальный вывод/UI/ошибка; только фактический прогон;
- график: реальные данные, оси и единицы, источник; без 3D;
- иллюстрация: обложка/концепция/настроение; запрещён фальшивый интерфейс.

## Пайплайн

1. Тезис.
2. Тип.
3. Исходник в `assets/visuals/chapter-NN/`.
4. Рендер PNG/SVG.
5. Проверка глазами: кириллица, шрифты, границы.
6. Вставка: презентация `![alt](../../assets/visuals/...)`, лекция `![alt](assets/visuals/...)`.
7. Один визуал — один тезис; подпись объясняет, что смотреть.
8. Коммит исходника и рендера.

## Excalidraw

MCP `excalidraw`, canvas `http://127.0.0.1:3010`. `clear_canvas` → `batch_create_elements` → `export_to_image` (SVG/PNG) → `export_scene` (`.excalidraw`). Формат 16:9, 1600×900; заголовок 44 px, подписи 30 px, минимум 24 px; шрифт `nunito`/`helvetica`; стрелки привязывать `startElementId`/`endElementId`. После экспорта открыть PNG и проверить обрезку/перекрытия/мелкий текст. Исходник обязателен.

## Скриншоты

`node scripts/shot.mjs --command "..." --out dist/shots/name.png`, `--url`, `--routes`. Скрипт проверяет секреты и возвращает код 2 при утечке. Рендер: тёмное окно, моноширинный шрифт, 1600×900. Проверить на токены/пароли/ФИО/пути/адреса. В заметках слайда сказать, что смотреть.

## Графики

Только реальные данные, подписать оси и единицы, указать источник; нет данных — не рисовать.

## Запреты

Схема ради схемы, скриншот «как должно быть», график без данных, мелкий текст, визуал повторяет текст, один визуал на несколько тезисов.
